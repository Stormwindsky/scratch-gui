# StormWarp GUI

**StormWarp** is a custom fork of [TurboWarp](https://turbowarp.org/), which is a high-performance mod of [Scratch 3.0](https://scratch.mit.edu/). This repository contains the interface components used to create and run projects within the StormWarp ecosystem.

Specifically, this is the `scratch-gui` layer modified for use in TurboWarp and further customized for StormWarp.

## Setup

See https://docs.turbowarp.org/development/getting-started to setup the complete TurboWarp environment.

If you just want to play with the GUI then it's the same process as upstream scratch-gui.
